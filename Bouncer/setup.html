Local AI setup

Bouncer uses Llama.app on your Mac with the d1 text model. Posts and filter phrases stay on your device. Images and videos are never sent to the model.

Use Bouncer in Brave or Chrome. Automatic filtering needs the setup below; manual Bounce and Restore are available while the model is unavailable.

1. Start Llama.app

Install Llama.app, the llama.cpp team’s macOS menu-bar app, from llama.app or with Homebrew:

brew install --cask llama-app

Open the app and turn on Launch at login so it is always there. Keep its local server at http://127.0.0.1:9931.

Llama.app answers requests from any web origin by default. While it is running, websites can attempt to reach its local API. Brave asks before websites can access localhost; review the prompt for the requesting site.

2. Install the d1 model

The required model is LiquidAI/d1-2B-GGUF:Q8_0. With the Hugging Face CLI installed, run:

hf download LiquidAI/d1-2B-GGUF d1-2B-Q8_0.gguf

This downloads only d1-2B-Q8_0.gguf to the Hugging Face cache. Use the default cache location, without a separate download directory:

~/.cache/huggingface/hub/models--LiquidAI--d1-2B-GGUF/snapshots/<revision>/d1-2B-Q8_0.gguf

Reopen Llama.app so its cache scan discovers the downloaded model. Bouncer uses the text model only; no projector download is needed.

3. Set the model settings

Quit Llama.app, then add the following section to ~/.config/llama/models.user.ini. If the section already exists, update its settings instead of adding a duplicate. Preserve your other model sections.

[LiquidAI/d1-2B-GGUF:Q8_0]
ctx-size = 4096
parallel = 1
batch-size = 4096
ubatch-size = 4096
no-mmproj = true

Do not add hf-repo to this section: it can start a separate download under /tmp. Llama.app’s cache scan supplies the model’s file location. Use models.user.ini for these settings; Llama.app regenerates models.ini.

Reopen Llama.app after saving the file.

4. Check Bouncer

Load Bouncer unpacked from Brave’s or Chrome’s extensions page with Developer mode enabled. Open Bouncer’s settings and click Check status. A ready status means Llama.app can see the model with the required settings. Checking status does not load it; the first post that needs filtering does.

  • Start Llama.app: open the app and turn on Launch at login.
  • Install the d1 model: check the exact download and cache location in step 2, then reopen Llama.app.
  • Llama.app needs these settings: check the model section in step 3, then reopen Llama.app.

If Bouncer’s background is out of date, reload Bouncer in your browser’s extensions page and reopen settings.

This help page makes no requests to Llama.app and cannot change your model files or settings.
