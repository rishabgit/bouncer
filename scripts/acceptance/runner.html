Before starting

Keep this tab visible, the Mac awake, and all extension inspectors and other Bouncer popup windows closed. Close any other extension pages in this test profile. The page will run three synthetic astronomy, cooking and neutral cases per engine, switch both ways, and attempt a Browser initialization retirement check.

Each engine then gets a full 120-second quiet interval with the popup removed and no extension messages, storage reads or native requests. Moving away, sleeping, reloading or suspending this page makes that interval inconclusive.

The product’s configured retention is one minute. A context/residency snapshot after 120 quiet seconds checks that resources have expired by then; it does not measure the exact release time.

Start explicitly authorizes downloading the pinned Browser model: 2,008,432,640 bytes (2.01 GB) from Hugging Face into this disposable profile if it is missing. Nothing changes the shared native model, Ollama setup or the daily profile.

    Evidence and boundaries

    Verdict checks are smoke checks, not a model-quality study. This page does not test X feed behavior, manual Bounce/Restore, suggestions, toolbar/focus behavior, native interruption/recovery, normal login, logout or reboot. It performs no warmup, force unload, cache deletion, permission manufacture or native configuration change.

    The shared Ollama service is outside profile isolation. A resident candidate after quiet is inconclusive because another client may extend residency. Any native uncertainty stops the run and preserves the profile. Do not restart Ollama or clear a recovery fence as part of this runner.

    At the end, export the report and quit only the owned Chrome for Testing browser normally. Cache/profile cleanup is a separate guarded operator step; this page never deletes them.
